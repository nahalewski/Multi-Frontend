# 0.12.0 — XMB refinement and first public builds

## Downloads
- Windows x64: Blades360 0.12.0 portable executable.
- Android: Blades360 1.0 debug APK, rebuilt from the published Android source.
- SHA256SUMS.txt: checksums of both downloads.

## Windows highlights
- Six console-inspired themes with first-run console/theme preview.
- XMB category and utility icons, improved row spacing, layered moving waves, PS3 logo fade and theme-specific startup/navigation audio.
- ROM/PC library, RomM marketplace and save backup integration, emulator/core launching, artwork, controller support and themed overlays.
- Jellyfin, Plex, YouTube, IPTV guide and local media.
- Karaoke solo/remote duets, recordings, community sharing and voting, and consent-based vocal-stem stitching.

## Android
Existing Blades frontend with game library, emulation, media integrations and settings backup. Android does not yet include desktop XMB or karaoke/community functionality. This is a debug-signed development APK.

## Still pending
Emulator-specific netplay, account recovery, friends/invites, pitch scoring and Android parity. Internet latency affects live duet monitoring; vocal removal can leave artifacts. Mac release testing is not complete.

Console theme assets retain their original owners' rights. No game content, firmware or personal credentials are included.
