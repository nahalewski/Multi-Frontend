# PlayStation 5 theme — Windows 0.15.0

Adds Games and Media hubs, artwork backgrounds, library, settings, notifications, keyboard styling, startup animation and a bottom Control Center. Embedded games expose the existing save states, timeline, controller, capture and volume features through this theme. External games retain resume and close controls.

Initial setup persists progress and includes controller, language, network, display safe area, HDR settings review, motion/power preference, frontend acknowledgement, updates, local user/avatar, optional account and backup transfer. It supports returning-user selection. This is frontend setup, not PSN provisioning or Sony console firmware. HDR and Windows settings remain dependent on hardware support; unavailable capabilities are not simulated.

The boot animation is drawn locally. Sound assets are attributed in assets/ps5/SOURCES.md and its manifest; upstream attribution is not an independent guarantee of bit-perfect console recordings. No proprietary font is bundled. Android has not received this theme.
