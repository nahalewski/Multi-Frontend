# Series keyboard — 0.6.4

The Series theme now uses a bottom-docked, neutral charcoal keyboard with flat rectangular keys, white selection, green input/caps indicators, Segoe UI typography and compact controller hints. Multiple-field forms show the active field and keep LB/RB switching. Secret fields remain masked.

Series controller movement uses key geometry so the wide Space, Done and Cancel keys navigate predictably. Other themes retain their existing layout/navigation.

Validated physical typing, masked inputs, field switching, shift/delete, controller geometry, submit/cancel cleanup, 800×500 fit and Blades isolation. Screenshot reviewed; packaged-build smoke checked.
