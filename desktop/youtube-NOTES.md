# Desktop YouTube

Integration: instantiate `createYoutube` from `youtube-main.cjs` after Electron is ready, with `{directory:path.join(app.getPath('userData'),'youtube-runtime'),getState:()=>state,save,executable:process.execPath}`. Route `youtube:*` commands to its `command(name,args)` method; call `close()` during shutdown. Load `youtube-renderer.js` after `renderer.js`. Add `['YouTube',()=>BladesYouTube.home()]` to Media Center. At the beginning of the main `control(key)`, use `if(window.BladesYouTube?.handleControl(key))return;`. Before starting non-YouTube playback, call `BladesYouTube.stop()` if `isPlaying()` is true; call it in the generic `stop` handler as well. Renderer needs the existing local Blades show/input/toast/run/call helpers and #player video. No Node APIs are exposed to the renderer.

The pinned verified release is yt-dlp **2026.10.26**. First use downloads the official Windows x64 standalone or macOS universal standalone; updates fetch current stable metadata and the release's SHA256 manifest from official GitHub HTTPS endpoints. Download size is bounded and SHA256 must match before execution. Executables include Python and yt-dlp-ejs. Electron's embedded Node runs EJS with `ELECTRON_RUN_AS_NODE=1` and the explicit `--js-runtimes node:<executable>` option; no system Python/Node is required. The packaged Electron build must keep its RunAsNode fuse enabled (the default). macOS binary execution still requires platform testing/signing assessment. Runtime requests ignore all external yt-dlp config files, never use a shell, never use cookies, and suppress stdout/stderr exposure in errors.

Public search, URLs, channel/playlist browsing with pagination, locally stored subscriptions/feed, favorites, Watch Later, queue, resume history, creator caption tracks, chapters, quality, speed, aspect and public read-only comments are implemented. Subscriptions and favorites do not affect a YouTube account. Private, age-restricted, region-restricted or login-required media can fail. Streams use Electron-supported direct formats; separate audio/video streams are synchronized in the player. Feed refresh is bounded to the first 12 subscriptions and 5 uploads per channel, and indicates partial results. No live chat, posting, account subscriptions, or paid-content bypass is provided.

Official references: https://github.com/yt-dlp/yt-dlp ; https://github.com/yt-dlp/yt-dlp/wiki/EJS ; https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26 . yt-dlp is Unlicense; standalone distributions include third-party libraries and licenses described in its README. The app obtains unmodified official executables on demand rather than rehosting them.
