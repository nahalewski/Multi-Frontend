# PS4 theme resources

Source: [d4v1-sudo/Ps4-UI](https://github.com/d4v1-sudo/Ps4-UI), commit `bc62c9b7d1e1831fcc2c99b683983984c52ea975`. Download URLs, byte lengths and SHA-256 checksums are recorded in manifest.json. Upstream repository's MIT notice is preserved in LICENSE-upstream.txt.

The repository recreates PlayStation 4. Sony names, marks, console graphics and original sounds remain the property of their respective owners. The upstream MIT software license is not a claim that Sony intellectual property has been independently relicensed. This is an unofficial frontend theme. No Sony SST font, game artwork or background music was copied.

Menu mappings: navigate.mp3 for directional movement; reward.mp3 for notifications; shutdown.mp3 for shutdown presentation; startup.mp3 for PS4 startup. Listen/inspect before assigning confirm/back: the source provides no separately named confirm or cancel effect.

## Anniversary reference

The PS4 option should be labeled **PlayStation 20th Anniversary (2014)**. The official PlayStation Blog lists it among PS4 themes: https://blog.playstation.com/archive/2015/07/23/a-full-list-of-all-available-ps4-themes/

The gray original-PlayStation palette, multicolor PS emblem and controller-symbol accents may be recreated with live UI graphics. Do not label this a PS5 30th-anniversary theme. No verified redistributable anniversary-specific sound file or boot video was found, so none is bundled here. An anniversary-inspired canvas animation should be described as a recreation, not an original boot recording.

## PS4 refinement resource update

Anniversary graphics: [KnuxBoy04/skin.orbis](https://github.com/KnuxBoy04/skin.orbis), commit `f2678080cc6355e87140740fe7221e4111783717`, `THEMES/PlayStation Anniversary`. Orbis was originally created by Toyota12303. Upstream contains both CC0 (`LICENSE`) and CC BY-NC-SA 3.0 (`LICENSE.txt`) notices; both are retained, and no claim is made that these relicense Sony console artwork. `anniversary/` contains background textures and individual icons, not screenshots used as UI. The UI remains live.

Named PS4 effects: [DAK404/Kodi-PS4-Soundtheme](https://github.com/DAK404/Kodi-PS4-Soundtheme), commit `6aa6904dd88ffb528039569075498efd6a22941b`, originally Toyota12303; restored by SZNX and XML corrections by DAK404. Source files are explicitly Select, Back, Move, Notification and Startup. No standalone license notice is supplied for this pack; original Sony sounds retain their owners’ rights. These are not presented as newly MIT-licensed sounds. Exact source URLs and hashes are in manifest.json.

No verified anniversary-specific sound recording is bundled. The anniversary texture set does not contain audio. Standard PS4 effects remain the documented fallback.

The source Login.wav is a 112-second recording with additional audio, not a clean login cue. It was reviewed but not bundled.
