# Console portrait collection

100 original AI-generated portraits created for this frontend on 2026-11-15 with the image-generation tool. No upstream avatar assets were copied. The ten collections correspond to Blades, NXE, Metro, Metro Revised, Series, XMB, PS4, PS4 Anniversary, PS5 and Series 25th Anniversary.

The original atlas is retained as console-portraits.png. avatar-catalog.js defines reviewed cell boundaries; the picker renders thumbnails and saves the selected cell as the user's custom profile image. Existing pictures remain selectable. These are inspired by console-era colors and visual styles, not official Sony/Microsoft avatars.
