# Desktop 0.4.0

Setup includes live dashboard previews and immediate Blades/NXE switching. Family Settings has separate PIN-protected game, online and transfer controls. Desktop menus hide native scrollbars while retaining scrolling. Blades options and embedded-game Guide use the Android curved panel geometry.

PC Games discovers installed titles from Steam, Epic, GOG, Xbox Games, EA, Ubisoft and Battle.net metadata across mounted Windows drives. It does not classify every executable as a game. Unrecognized standalone installs and unsupported launcher metadata are not automatically imported.

The designated N: volume is enrolled with Xbox360.ini, a persistent drive UUID and Windows volume identity. Detection follows drive-letter changes and ignores marker copies on other volumes. Content is organized beneath Xbox360 into Games, Media, DVR, Metadata and Transfers. Local content is copied without deleting originals. PC installs are archives; DRM or launcher verification may be required to use copies. RomM and media downloads depend on server download permissions.

IPTV DVR requires ffmpeg on PATH and a compatible provider stream. Recordings and scheduled programmes use the registered drive, pause the preview, and appear in its gallery. The app must remain running for schedules; this is not an operating-system recording service. Recording was verified with generated video, not a live subscription programme.
