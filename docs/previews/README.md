# Current desktop preview gallery

51 fresh 1920 × 1080 captures of the interactive Windows **0.16.0 development build**, grouped by console theme and app. These are actual app renders with synthetic demonstration libraries, artwork, accounts and guide data—not screenshots used as the app interface.

The published release and source snapshot remain **0.12.0**. This gallery previews newer local desktop work; it does not establish Android feature parity or verify live service playback.
